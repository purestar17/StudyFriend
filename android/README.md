# 공부 친구 (초등 학습 태블릿 앱) - 1단계 MVP

Android 태블릿용 학습 앱입니다. Kotlin + Jetpack Compose, 기기 안 저장(Room).

## 들어 있는 기능
- 5과목: 수학(학년별 자동 출제 1~6학년), 한자(8급·7급·6급), 영어 단어, 영어 회화, 국어 어휘
- 영어는 태블릿 내장 음성으로 발음 듣기
- 정답/오답 즉시 확인, 틀린 문제 다시 보기
- 정답률 기반 레벨 자동 조정 (90% 이상 한 단계 올림, 50% 미만 한 단계 내림, 관리자가 끌 수 있음)
- 관리자 모드(오른쪽 위 톱니바퀴, 처음 비밀번호 0000)
  - 과목별 레벨 직접 선택
  - 학습 기록과 최근 7일 과목별 정답률
  - AI 제공자 선택(Claude / GPT), 중계 서버 주소, 실시간 음성 옵션 (연결은 3단계)
  - 학생 별칭, 한 번에 푸는 문제 수, 비밀번호 변경

## 설치 방법 (APK)
1. `공부친구-0.1.0-debug.apk`를 태블릿으로 옮깁니다 (USB, 구글 드라이브, 카카오톡 나에게 보내기 등).
2. 태블릿에서 파일을 누르고, "출처를 알 수 없는 앱 설치 허용"을 요청하면 허용합니다.
3. 설치 후 "공부 친구" 앱을 엽니다.

## 직접 빌드
Android Studio로 이 폴더를 열고 실행하거나, `./gradlew assembleDebug`.

## 다음 단계
- 2단계: 정해진 시간에 자동 실행 + 학습 완료 전 다른 앱 차단 (Device Owner + Lock Task)
- 3단계: AI 연동 (수준 판정, 난이도 조정, 영어 회화, 선택 시 ChatGPT 앱 연동)
- 4단계: 문제 콘텐츠 확충, 보호자 리포트

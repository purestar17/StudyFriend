# 공부 친구 웹 버전

Android 앱(`android/`)과 같은 문제와 규칙을 브라우저에서 바로 써 볼 수 있게 옮긴 테스트용 버전입니다. 빌드 과정 없이 파일 그대로 동작합니다.

- 주소: main 브랜치에 반영되면 GitHub Pages로 자동 배포됩니다 (`https://purestar17.github.io/StudyFriend/`).
- 로컬에서 보기: `web/index.html`을 브라우저로 열면 됩니다.
- 학습 기록과 설정은 그 브라우저에만 저장됩니다.
- 예약 시간 자동 실행과 화면 잠금은 Android 앱에서만 됩니다.

## 파일
- `content-data.js` 문제 데이터 (Android `content/` 폴더와 같은 내용)
- `logic.js` 문제 생성, 채점, 레벨 자동 조정 규칙
- `math-workbook.js` 수학 문제 (학년별 단원, 심화 사고력·응용력)
- `word-writer.js` 영어 단어 손글씨 쓰기 (네 줄 공책 칸, 모양 비교로 확인)
- `brush.js` 한자 쓰기 붓펜 효과 (펜 압력·쓰는 빠르기에 따라 굵기)
- `schedule.js` 학습 시간표 계산 (지금 시간 칸, 오늘의 과제 진행). Android 쪽 `Schedule.kt`와 같은 규칙
- `notepad.js` 연습장 (오른쪽 손잡이를 당기거나 눌러서 꺼냄, 무지·밑줄·한자노트·영어노트, 펜 압력 굵기, 펜을 쓰면 손바닥 터치 무시)
- `hanja-study.js` 한자 급수별 학습 (묶음 나누기, 활동 문제 만들기, 복습 상자)
- `hanja-radicals.js` 한자 부수 자료 (Make Me a Hanzi 사전에서 뽑아 한국식 이름을 붙임)
- `rewards.js` 포상 뽑기 규칙 (조건, 하루 최대, 확률) 과 그날 쓴 면제권 계산
- `ai.js` AI 선생님 (앱에서 관리자의 ChatGPT 계정으로 묻기: 틀린 문제 힌트·설명, 비슷한 문제 만들기, 수준 분석). 로그인·요청은 앱의 `ChatGpt.kt`
- `ocr.js` 사진 속 단어 목록 읽기 (Tesseract.js, 처음 쓸 때 CDN에서 받아 기기 안에서 처리)
- `talk-topics.js` 영어 회화 "오늘의 대화" 주제와 미리 볼 표현
- `figures.js` 수학 그림 (시계, 수 모형, 도형, 분수, 각, 막대그래프, 넓이, 직육면체)
- `pen.js` 펜으로 쓴 숫자 답 읽기 (기기 안에서 동작)
- `app.js` 화면 (홈, 문제, 결과, 관리자 비밀번호, 관리자 모드)
- `style.css` 디자인

문제를 추가하거나 고칠 때는 Android 쪽 `content/*.kt`와 `content-data.js`를 함께 바꿔야 합니다.

## 한자 학습
- 급수별 한자: 한국어문회 한자능력검정시험 8급~4급 배정 한자 1,000자 (`content-data.js`, 8급·7급·6급·5급·4급Ⅱ·4급).
- 획순 데이터 (모두 한국식 획순, 급수별로 `strokes/levelN.json`에 묶음, Arphic Public License `strokes/ARPHICPL.TXT`):
  - 8급~5급: [animCJK](https://github.com/parsimonhi/animCJK) 한국 한자(svgsKo) (`strokes/COPYING-animCJK.txt`)
  - 4급Ⅱ·4급: [hanjamaster-kaiti-strokes](https://github.com/heyday07/hanjamaster-kaiti-strokes). 일부 글자는 한국식 자형 대체본(alt)을 썼고, 硏鄕鑛姉鬪 5자는 데이터가 없어 획순 학습에서 빠집니다.
- 쓰기 연습: [Hanzi Writer](https://hanziwriter.org) (MIT, `vendor/`). 따라 쓰기·혼자 쓰기는 붓펜 효과(`brush.js`)로 그립니다: 스타일러스는 누르는 힘, 손가락·마우스는 쓰는 빠르기에 따라 굵기가 바뀌고 시작과 끝이 가늘어집니다.
- 시험형 문제 데이터: `hanja-exam-data.js` (한자어, 반대자, 사자성어)

## 한자 급수별 학습
- 한자 → 급수별 학습: 급수 한자를 묶음(관리자 설정 5·6·8·10자)으로 나눠 학습지처럼 익혀요.
- 단계: 훈음 카드 → 짝 맞추기 → 따라 쓰기·혼자 쓰기 → 한자어 읽기·뜻 → 문장 빈칸 채우기 → 같은 부분(부수) 찾기 → 확인 시험.
- 확인 시험 결과로 글자마다 복습 상자(1~5)가 바뀌고 1·2·4·7·15일 뒤 '복습 시험'에 다시 나와요. 진도와 자주 틀린 한자는 관리자 → 학습 레벨에서 봐요.

## 수학
- 학년은 관리자가 정합니다(자동 레벨 조정은 기본 꺼짐, 관리자 모드에서 켤 수 있음).
- 학생은 수학 메뉴에서 단원을 골라 풉니다. 학년마다 교과 단원을 4~8개로 묶었습니다 (`MATH_UNITS`).
- 학년마다 심화 문제 두 가지: 사고력(규칙 추론, 거꾸로 생각하기, 수 카드 등)과 응용력(여러 단계 문장제) (`MATH_CHALLENGE`).
- 객관식은 보기를 고른 뒤 확인을 눌러야 채점됩니다.
- 숫자 답은 펜(손글씨)으로 쓰거나 키패드로 입력합니다. 관리자 모드 > 일반, 또는 문제 화면 아래에서 바꿀 수 있습니다.
- 손글씨 인식은 $P 점구름 인식기로 기기 안에서만 처리합니다 (서버 전송 없음). 소수점은 작은 점으로 씁니다.

## 영어 단어
- 기본 단어(레벨별)와 관리자가 만든 단어장으로 시험을 봅니다. 관리자 모드 > 영어 단어장에서 영어칸·뜻칸을 짝지어 입력하고, 점선 "+ 단어 추가"로 한 줄씩 늘립니다. 뜻은 쉼표로 여러 개 넣을 수 있습니다 (뜻 묻기는 전체 뜻이 보기, 영어 묻기는 뜻 하나로 물음).
- "사진으로 한 번에 추가": 단어 목록 사진을 기기 안에서 글자 인식(영어+한국어)해 칸에 채웁니다. 인식이 틀릴 수 있어 저장 전에 확인·수정하도록 했고, 뜻을 못 읽은 줄은 빨간 테두리로 표시합니다. 손글씨보다 인쇄된 목록이 잘 읽힙니다.
- "여러 줄 붙여 넣기"로 "영어 - 뜻" 목록이나 엑셀 두 칸을 한꺼번에 넣을 수도 있습니다.
- 문제를 푼 뒤 그 단어를 손으로 씁니다: 따라 쓰기(흐린 글자 위) / 혼자 쓰기 / 쓰기 없음 중 관리자가 고릅니다.
- 쓰기 확인은 글자를 하나하나 읽는 인식이 아니라 정답 단어 모양과 겹치는 정도, 글자마다 위·아래로 나가는 획의 위치를 비교하는 방식입니다. 두 번 틀리면 건너뛸 수 있습니다.

## 영어 회화
- 관리자가 '오늘의 대화 주제'를 고르거나 직접 씁니다 (정하지 않으면 날마다 추천 주제).
- 학생 화면에서 주제와 표현을 미리 보고, 버튼을 누르면 ChatGPT(`chatgpt.com/?q=`)가 시작 문장과 함께 열립니다. 시작 문장은 클립보드에도 복사됩니다.
- 관리자 모드에서 연결 주소를 정할 수 있습니다: 비우면 새 채팅(규칙+주제를 함께 보냄), 맞춤 GPT·프로젝트 주소면 그 지침을 쓰는 새 대화에 주제만 보냄, 특정 채팅(`/c/…`) 주소면 그 대화방으로 이동하고 주제 문장은 복사됨.
- '대화를 끝내는 말'(기본 "Goodbye, teacher!")을 학생이 말하면 ChatGPT가 배운 표현 3개를 정리하고 대화를 마치도록 규칙에 넣습니다. 앱이 ChatGPT 대화를 직접 닫거나 내용을 받아 올 수는 없습니다.
- ChatGPT는 보안 설정 때문에 다른 페이지 안에 넣어(iframe) 보여 줄 수 없어서 새 창(앱)으로 엽니다. 돌아와서 '대화를 마쳤어요'를 누르면 대화 시간이 기록됩니다.

- 아이가 영어 회화 화면에서 주제를 고르거나(관리자가 고른 주제, 없으면 날마다 4개 추천) 직접 써요. ChatGPT 연결 주소(맞춤 GPT·프로젝트)를 넣으면 'Let's talk about "주제".' 같은 시작 문장만 보내요(관리자에서 문장 수정).

## 학습 시간표 (2단계)
- 관리자 → 학습 시간표: 요일·시각(여러 개), 요일별 과제(과목별 횟수, 왼쪽 세로 요일 메뉴).
- 시간 안에 있으면 처음 화면 위에 남은 과제가 보이고, 과제 칸을 누르면 그 과목으로 가요.
- 웹 버전은 보여 주기만 하고, 자동 실행·잠금은 Android 앱(`../android`)이 해요. 앱 안에서는 `window.StudyFriendApp`으로 연결돼요.

## 채점 방식
- 문제를 푸는 동안에는 맞았는지 알려 주지 않고, 마지막에 결과(문제별 ○✕)로 보여 줘요.
- 결과에서 틀린 문제를 누르면 그 문제만 다시 풀어요(바로 채점, 두 번 틀리면 정답 보여 줌).
- 틀린 문제는 오답 노트(관리자 → 오답 노트, 최근 500개)에 저장되고, 다시 풀어 맞히면 '고침'으로 표시돼요.
- 영어 단어 손글씨 쓰기는 문제를 다 푼 뒤 결과 전에 한꺼번에 해요.

## 연습장
- '새 종이'를 누르거나 앱을 닫으면 지금 종이가 PNG로 저장돼요(IndexedDB, 최근 60장, 관리자 → 연습장). 앱에서는 갤러리 Pictures/공부친구에도 저장(Android 10 이상).

- 손잡이를 당긴 만큼만 나와 있어요(최소 280px). 열린 연습장은 손잡이를 오른쪽으로 휙 빠르게(0.2초 안에 40px 넘게) 밀거나 최소 크기보다 40px 더 밀면 닫히고, 천천히 끌면 크기만 바뀌어요. 도구 버튼은 세 줄(되돌리기·비치게·새 종이 / 배경 / 펜 색·선 굵기(굵기 그림 목록)·지우개)로 자리가 고정돼 있어요. '비치게'를 켜면 종이가 반투명해져 뒤의 문제가 보여요.

## 포상
- 관리자 → 포상에서 켜고, 나오는 때(학습을 끝까지 하면 / 정답률 N% 이상), 하루 최대 개수, 포상 목록과 확률(합 100% 이하, 나머지는 꽝)을 정해요.
- 포상 종류: 과목 면제권(그날 그 과목 과제를 다 한 것으로), 하루 면제권(그날 과제 모두), 직접 쓴 포상(보호자가 주고 관리자 '지급' 또는 아이 보관함 '보호자 확인'으로 표시). 관리자 저장 안내는 토스트로 떠요.
- 아이는 결과 화면에서 선물 상자를 열고, 처음 화면 '🎁 보관함'에서 면제권을 써요. 쓴 면제권은 오늘의 과제 진행에 들어가서 과제가 다 차면 잠금이 풀려요.

## AI 선생님 (3단계, Android 앱에서만)
- 관리자 → AI 설정 → ChatGPT로 로그인: OpenAI 'Sign in with ChatGPT' 토큰 공유(OAuth + PKCE, 127.0.0.1로 돌아옴). API 키 없이 Go·Plus·Pro 정액제 사용량으로 Responses API를 불러요.
- 다시 풀기에서 틀리면 'AI 선생님 힌트'(정답은 말하지 않음), 두 번 틀리면 '설명'.
- 결과 화면 '틀린 문제와 비슷한 문제 5개 풀기': AI가 객관식 문제를 만들어요(정답이 보기에 있는지 등 형식은 검사하지만 내용이 틀릴 수 있어요).
- 학습 레벨 탭 'AI 수준 분석': 최근 기록과 오답 노트를 보내 과목별 레벨을 추천받고 버튼으로 바로 바꿔요. 아이 이름은 보내지 않아요.
